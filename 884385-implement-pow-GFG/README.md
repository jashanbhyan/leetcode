# [Implement Pow](https://www.geeksforgeeks.org/problems/powx-n/1)
## Medium
Implement the function power(b, e), which calculates b raised to the power of e (i.e. be).
Examples:
Input: b = 3.00000, e = 5Output: 243.00000
Input: b = 0.55000, e = 3Output: 0.16638
Input: b = -0.67000, e = -7Output: -16.49971
Constraints:
-100.0 &lt; b &lt; 100.0-109 &lt;= e &lt;= 109Either b is not zero or e &gt; 0.-104 &lt;= be &lt;= 104
